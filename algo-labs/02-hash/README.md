# 专题 02：哈希表

> 核心思想：用 O(1) 的查找换 O(n) 的空间，把"线性扫描"变成"直接定位"。

## 适用场景

- 快速查找/去重（两数之和、两数之差）
- 分组（字母异位词、用户按城市分组）
- 频率统计（TopK、众数）

## 三道经典题

---

### 题 1：Two Sum（无序数组，找两数之和等于 target）

**题目**：给定数组 `nums` 和目标值 `target`，返回两个下标。

**思路**：边遍历边建哈希表，键是数值，值是下标。对于当前数 `x`，检查 `target - x` 是否已在表中。

**复杂度**：时间 O(n)，空间 O(n)

**面试追问**：
- "如果数组有序，能不能不用哈希表？" → 可以，双指针 O(n) 时间 O(1) 空间（专题 01）
- "如果输入是数据流（在线版）？" → 哈希表存值到索引列表，来一个查一个

**破坏练习**：输入有重复元素 `[3, 3]` target=6，观察如何处理（应该返回 `[0, 1]`）

---

### 题 2：字母异位词分组（Group Anagrams）

**题目**：把字母异位词组合在一起。`["eat", "tea", "tan", "ate", "nat", "bat"]` → `[["eat","tea","ate"], ["tan","nat"], ["bat"]]`

**思路**：异位词的字母排序后相同。用排序后的字符串作为 key，原字符串作为 value 分组。

**复杂度**：时间 O(n · k log k)（n 个字符串，每个长度 k），空间 O(n · k)

**面试追问**：
- "不用排序能不能做 key？" → 用字母频率数组（26 个计数）转字符串作为 key，时间降到 O(n · k)
- "如果是中文词语分组？" → 用字符 Unicode 排序或拼音排序

**破坏练习**：输入含空字符串 `""`，观察分组结果

---

### 题 3：最长无重复字符子串（Longest Substring Without Repeating）

**题目**：找不含重复字符的最长子串长度。`"abcabcbb"` → 3（`"abc"`）

**思路**：滑动窗口 + 哈希集合：
- 右指针扩张，遇到重复字符时左指针收缩到重复字符的下一个位置
- 用集合记录窗口内的字符

**复杂度**：时间 O(n)，空间 O(min(n, m))（m 是字符集大小）

**面试追问**：
- "如果字符集已知（如 ASCII），怎么优化？" → 用 boolean 数组或位图代替 HashSet
- "如果要返回子串本身，不只是长度？" → 记录最大长度时的左右指针

**破坏练习**：输入全相同字符 `"aaaaa"`，观察窗口如何收缩

## 哈希表的本质

哈希表的三个核心操作：
1. **put(key, value)**：插入/更新，O(1) 平均
2. **get(key)**：查找，O(1) 平均
3. **containsKey(key)**：判断存在，O(1) 平均

所有题目都是这三个操作的组合。面试时先想"哪些信息需要 O(1) 查找"，再设计 key 和 value。
