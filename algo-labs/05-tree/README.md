# 专题 05：二叉树

> 核心思想：递归是二叉树的灵魂，每道题都可以用"根-左-右"的递归框架思考。

## 适用场景

- 树形结构数据（文件系统、组织架构、DOM 树）
- 分治思想（左右子树独立处理）
- 路径问题（根到叶、节点到节点）

## 三道经典题

---

### 题 1：二叉树的遍历（前序、中序、后序、层序）

**题目**：实现四种遍历方式。

**思路**：
- **前序**（根-左-右）：先访问根，再递归左子树，再递归右子树
- **中序**（左-根-右）：先递归左子树，再访问根，再递归右子树
- **后序**（左-右-根）：先递归左子树，再递归右子树，最后访问根
- **层序**（BFS）：用队列，按层遍历

**复杂度**：时间 O(n)，空间 O(h)（递归栈，h 是树高）

**面试追问**：
- "迭代写法（不用递归）？" → 用显式栈模拟递归，前序最简单，中序需要"一路向左再回溯"
- "前序+中序能唯一确定一棵树吗？" → 能（前序第一个是根，中序分左右子树）

**破坏练习**：画一棵树，手动写出四种遍历结果，再跑代码验证

---

### 题 2：二叉树的最大深度（Maximum Depth）

**题目**：求根节点到最远叶子节点的最长路径上的节点数。

**思路**：递归：`depth = 1 + max(leftDepth, rightDepth)`

**复杂度**：时间 O(n)，空间 O(h)

**面试追问**：
- "最小深度呢？" → 注意叶子节点的定义（左右子树都为空），不能简单取 min
- "如果是 N 叉树？" → 递归所有子节点取 max

**破坏练习**：空树（返回 0）、只有根（返回 1）、完全不平衡树

---

### 题 3：翻转二叉树（Invert Binary Tree）

**题目**：翻转一棵二叉树（左右子树互换）。

**思路**：递归交换每个节点的左右子树。

**复杂度**：时间 O(n)，空间 O(h)

**面试追问**：
- "迭代写法？" → 用队列或栈，层序/前序遍历，每访问一个节点就交换它的左右孩子
- "对称二叉树怎么判断？" → 递归比较左子树的左和右子树的右

**破坏练习**：画一棵树，手动翻转，再跑代码验证

## 二叉树的本质

所有二叉树题目的核心是**递归思维**：
1. **基本情况**：空树或叶子节点怎么处理
2. **递归关系**：当前节点的结果如何由左右子树的结果组合
3. **遍历顺序**：前序/中序/后序/层序，选择取决于"根在什么时候访问"

面试时先画树，标注递归关系，再写代码。
