# 专题 08：图

> 核心思想：图是通用的关系模型，BFS/DFS 是基础遍历，拓扑排序和并查集是高频应用。

## 适用场景

- **依赖关系**：课程表、任务调度、编译顺序（拓扑排序）
- **连通性**：社交网络、岛屿数量（DFS/BFS/并查集）
- **最短路径**：地图导航、网络路由（BFS 无权、Dijkstra 有权）

## 三道经典题

---

### 题 1：图的遍历（BFS 与 DFS）

**题目**：给定邻接表，实现广度优先和深度优先遍历。

**思路**：
- **BFS**：用队列，逐层扩展（先访问所有邻居，再访问邻居的邻居）
- **DFS**：用递归或栈，一路走到底再回溯

**复杂度**：时间 O(V+E)，空间 O(V)（visited 集合 + 队列/递归栈）

**面试追问**：
- "怎么判断图是否有环？" → DFS 时遇到已访问且不是父节点的邻居
- "有向图和无向图的遍历区别？" → 有向图需要记录入度，无向图需要防止回头

**破坏练习**：构造不连通图，观察遍历结果（只访问一个连通分量）

---

### 题 2：课程表（拓扑排序）

**题目**：给定课程依赖关系，判断是否能完成所有课程（检测 DAG 是否有环）。

**思路**：Kahn 算法（BFS 拓扑排序）：
- 计算每个节点的入度
- 入度为 0 的节点入队
- 每次取出队首，把它的所有邻居入度 -1，入度变 0 就入队
- 最后看处理了多少节点（等于总数说明无环）

**复杂度**：时间 O(V+E)，空间 O(V+E)

**面试追问**：
- "如果要输出拓扑序列？" → 记录出队顺序
- "DFS 怎么做拓扑排序？" → 后序遍历的逆序（完成时间从晚到早）
- "如果有多个合法拓扑序？" → 任意一个都对，队列顺序决定

**破坏练习**：构造有环图（如 0→1→2→0），观察算法检测到环

---

### 题 3：岛屿数量（Number of Islands）—— 并查集或 DFS

**题目**：二维网格，'1' 是陆地，'0' 是水，计算岛屿数（四连通）。

**思路**（DFS 法）：
- 遍历每个格子，遇到 '1' 就 DFS 标记所有相连的 '1' 为已访问
- 每次启动新的 DFS 就是一个新岛屿

**思路**（并查集法）：
- 每个 '1' 是一个集合，相邻的 '1' 合并
- 最后统计集合数

**复杂度**：时间 O(m×n)，空间 O(m×n)

**面试追问**：
- "如果是八连通？" → 改方向数组（8 个方向）
- "如果网格很大（10 亿×10 亿）但陆地很少？" → 用哈希表存陆地坐标，不用二维数组

**破坏练习**：全 '1' 网格、全 '0' 网格、单点岛屿

## 图的本质

图的核心是**关系建模**：
- 节点 = 实体（课程、城市、用户）
- 边 = 关系（依赖、距离、好友）

所有图题目都是：
1. 建图（邻接表或邻接矩阵）
2. 选择遍历方式（BFS 层次 / DFS 深度）
3. 根据问题定制访问逻辑（记录路径、检测环、统计分量）

面试时先说"怎么建图"，再说"怎么遍历"。
