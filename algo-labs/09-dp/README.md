# 专题 09：动态规划

> 核心思想：把大问题拆成子问题，用记忆化或表格避免重复计算。关键是定义"状态"和"状态转移方程"。

## 适用场景

- **最优解问题**：最大值、最小值、最长、最短
- **计数问题**：方案数、路径数
- **可行性问题**：能不能、是否可以

## 三道经典题

---

### 题 1：爬楼梯（Climbing Stairs）

**题目**：每次可以爬 1 或 2 个台阶，问爬到第 n 阶有多少种方法。

**思路**：
- 状态：`dp[i]` = 爬到第 i 阶的方法数
- 转移：`dp[i] = dp[i-1] + dp[i-2]`（从 i-1 爬 1 步，或从 i-2 爬 2 步）
- 初始：`dp[0] = 1, dp[1] = 1`

**复杂度**：时间 O(n)，空间 O(1)（滚动数组优化）

**面试追问**：
- "如果每次可以爬 1~k 步？" → `dp[i] = sum(dp[i-j])` for j in 1..k
- "如果某些台阶不能踩？" → 那些台阶 dp[i] = 0

**破坏练习**：n=1, n=2, n=3，手动推演验证

---

### 题 2：0-1 背包（Knapsack）

**题目**：n 个物品，每个有重量和价值，背包容量 W，求最大价值。

**思路**：
- 状态：`dp[i][w]` = 前 i 个物品、容量 w 时的最大价值
- 转移：`dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight[i]] + value[i])`（不选 vs 选）
- 初始：`dp[0][*] = 0`

**复杂度**：时间 O(nW)，空间 O(nW) 或 O(W)（滚动数组）

**面试追问**：
- "完全背包（物品可重复选）？" → 内层循环正序（0-1 是逆序）
- "如果要求恰好装满？" → 初始 dp[0]=0, dp[1..W]=-∞

**破坏练习**：所有物品重量都超过 W，观察结果全 0

---

### 题 3：最长递增子序列（LIS）

**题目**：找数组中最长严格递增子序列的长度。`[10, 9, 2, 5, 3, 7, 101, 18]` → 4（`[2, 3, 7, 101]`）

**思路**：
- 状态：`dp[i]` = 以 `nums[i]` 结尾的 LIS 长度
- 转移：`dp[i] = max(dp[j] + 1)` for j < i if nums[j] < nums[i]
- 答案：`max(dp)`

**复杂度**：时间 O(n²)，空间 O(n)

**面试追问**：
- "O(n log n) 解法？" → 贪心 + 二分（维护 tails 数组）
- "如果要输出子序列本身？" → 记录 parent 指针

**破坏练习**：全递减序列，观察结果全 1

## DP 的本质

所有 DP 题目的核心是三步：
1. **定义状态**：`dp[i]` 或 `dp[i][j]` 代表什么（子问题的解）
2. **写转移方程**：`dp[i]` 怎么由 `dp[i-1]`、`dp[i-2]` 等推导
3. **确定初始和边界**：`dp[0]`、`dp[1]` 的值，以及循环范围

面试时先说清这三步，再写代码。如果卡住，画表格手动推演前几项。
