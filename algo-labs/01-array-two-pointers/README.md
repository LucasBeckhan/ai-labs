# 专题 01：数组与双指针

> 核心思想：用两个指针从不同方向遍历，把嵌套循环 O(n²) 降为线性扫描 O(n)。

## 适用场景

- 有序数组的配对/搜索问题
- 容器/窗口类问题（找最大面积、最长子数组）
- 原地修改（去重、移动零）

## 三道经典题

---

### 题 1：Two Sum II（有序数组，找两数之和等于 target）

**题目**：给定升序数组 `numbers` 和目标值 `target`，返回两个下标（1-based）。

**思路**：左指针从 0 开始，右指针从末尾开始：
- 若 `sum < target`，左指针右移（增大和）
- 若 `sum > target`，右指针左移（减小和）
- 若 `sum == target`，找到答案

**复杂度**：时间 O(n)，空间 O(1)

**面试追问**：
- "如果数组无序怎么办？" → 排序 O(n log n) + 双指针，或用哈希表 O(n) 但需额外空间
- "如果有多组解，返回所有？" → 找到后继续移动指针，注意去重

**破坏练习**：改 target 为数组中不存在的值，观察指针最终位置

---

### 题 2：盛最多水的容器（Container With Most Water）

**题目**：给定高度数组 `height`，找两条线使容器盛水最多。面积 = min(h[i], h[j]) × (j-i)

**思路**：左右指针向中间收缩，**每次移动较矮的那根**：
- 为什么移矮的？因为面积受限于 min，移高的只会让 min 更小或不变，宽度还减小，面积必然变小
- 移矮的有可能遇到更高的，min 变大，面积有机会变大

**复杂度**：时间 O(n)，空间 O(1)

**面试追问**：
- "为什么贪心策略是对的？" → 反证法：假设最优解是 (i,j)，那么过程中一定会扫到它
- "如果改成三维（长方体容器）？" → 变成单调栈问题（专题 04）

**破坏练习**：打印每次移动前后的面积，观察"移矮的"策略如何逐步逼近最优

---

### 题 3：有序数组去重（Remove Duplicates）

**题目**：原地删除重复元素，返回新长度。

**思路**：快慢指针：
- 慢指针 `i` 指向下一个要写的位置
- 快指针 `j` 遍历数组，遇到 `nums[j] != nums[i-1]` 就写入 `nums[i]` 并 i++

**复杂度**：时间 O(n)，空间 O(1)

**面试追问**：
- "如果允许最多保留 2 个重复？" → 改为 `nums[j] != nums[i-2]`
- "如果是链表去重？" → 专题 03

**破坏练习**：输入全相同元素，观察最终数组

## 双指针的本质

所有双指针题的共同模式：
1. **维护一个不变量**（如 `left < right`、`nums[0..i-1]` 无重复）
2. **根据当前状态决定移动哪个指针**（贪心或单调性）
3. **指针移动后不变量仍成立**

面试时先说清不变量，再写代码，逻辑会清晰很多。
