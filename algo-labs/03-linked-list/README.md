# 专题 03：链表

> 核心思想：通过修改指针（引用）来操作节点，不需要移动元素。

## 适用场景

- 频繁插入/删除（O(1) 指针操作 vs 数组的 O(n) 移动）
- 不需要随机访问（链表不支持 O(1) 按下标访问）

## 三道经典题

---

### 题 1：反转链表（Reverse Linked List）

**题目**：反转单链表。`1->2->3->4->5` → `5->4->3->2->1`

**思路**：迭代法，维护三个指针：
- `prev`：前一个节点（初始 null）
- `curr`：当前节点
- `next`：下一个节点（保存，防止断链）

每步：`curr.next = prev`，然后三个指针整体前移。

**复杂度**：时间 O(n)，空间 O(1)

**面试追问**：
- "递归怎么写？" → `reverse(head.next)` 后，`head.next.next = head; head.next = null`
- "反转部分链表（m 到 n）？" → 找到 m-1 位置，反转 m~n，再接回去

**破坏练习**：输入空链表或单节点链表，观察边界处理

---

### 题 2：合并两个有序链表（Merge Two Sorted Lists）

**题目**：合并两个升序链表为一个新的升序链表。

**思路**：虚拟头节点 + 双指针：
- 比较两个链表当前节点，把较小的接到结果链表
- 某个链表走完后，把另一个剩余部分直接接上

**复杂度**：时间 O(n+m)，空间 O(1)

**面试追问**：
- "合并 K 个有序链表？" → 分治（两两合并）或最小堆（专题 06）
- "如果是有序数组而不是链表？" → 同样双指针，但需要额外数组存结果

**破坏练习**：一个链表为空，观察是否能正确处理

---

### 题 3：环形链表（Linked List Cycle）

**题目**：判断链表是否有环。

**思路**：快慢指针（Floyd 判圈算法）：
- 慢指针每次走 1 步，快指针每次走 2 步
- 如果有环，快慢指针一定会相遇
- 如果快指针走到 null，说明无环

**复杂度**：时间 O(n)，空间 O(1)

**面试追问**：
- "如果有环，怎么找入环点？" → 相遇后，一个指针回 head，两个都走 1 步，再次相遇就是入环点（数学可证）
- "为什么快指针走 2 步而不是 3 步？" → 走 2 步保证一定能相遇；走 3 步可能跳过

**破坏练习**：构造一个有环链表（尾节点指向中间某节点），验证检测正确

## 链表的本质

链表题目的核心是**指针操作**：
1. 画图：把节点和指针画出来，想清楚每一步怎么改
2. 边界：空链表、单节点、双节点，这些特殊情况先处理
3. 断链：改指针前先保存下一个节点，防止丢失

面试时先画图讲思路，再写代码，避免指针混乱。
