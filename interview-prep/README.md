# 大数据 / 数据平台 面试实战手册（目标档位：月薪 40k–50k）

> 定位：这是一份**面试官视角**的实战手册，与本目录平级的两个课程仓库（`k8s-labs`、`llmops-labs`）是它的"实训基地"——每道题都标注了"动手印证"实验，答得出来更要跑得出来。
> 适用档位：一线/新一线城市，资深大数据开发 / 数据平台工程师 / 数据仓库专家，月薪 40k–50k（对应大厂 6~7 级、独角兽资深/专家岗，通常要求 5–8 年经验）。
> 所有考点均基于 2025–2026 年企业真实在问的方向整理（数仓分层、数据倾斜、湖仓一体 Paimon、OLAP 选型 Doris/StarRocks、实时数仓、数据治理、K8s 云原生、LLMOps）。

## 一、面试官视角：40k–50k 的候选人该是什么样

月薪 4w–5w 不是"熟练工"价，是**"能对一片领域负责"**的价。我作为面试官，期望你具备下面六个维度的能力——每个维度我都会给出考察方式和代表性问题。**注意：这个档位挂掉的原因通常不是"不知道"，而是"回答停在背诵层面，没有量化、没有取舍、没有事故复盘"。**

| 维度 | 面试官期望（一句话画像） | 权重 |
|---|---|---|
| ① 数仓建模与业务理解 | 能独立负责一个业务域的模型设计，讲得清"为什么这样分层、为什么这样建维" | ★★★★★ |
| ② 大数据引擎深度 | Spark/Flink 不是"用过"，是**调优过、踩过坑、看过源码级原理** | ★★★★★ |
| ③ 实时数仓与湖仓 | 有 Paimon/Hudi/Iceberg 落地经验，讲得清流批一体的代价与收益 | ★★★★☆ |
| ④ 平台与云原生（K8s） | 数据负载上 K8s 的实践者，懂调度、资源、监控、排障 | ★★★★☆ |
| ⑤ 数据治理与质量 | 元数据、血缘、质量监控、成本治理——有体系而不是口号 | ★★★☆☆ |
| ⑥ 工程素养 | 线上事故复盘、量化表达、技术选型的权衡思维、跨团队推动 | ★★★★☆ |

**这个档位我必问的三类"分水岭问题"**：
1. **"说一次你造成的/你处理的最严重的线上事故"** —— 考复盘能力与诚实度。答不出具体细节（时间线、根因、止损、长效措施）直接降档。
2. **"这个技术你为什么选它，放弃了什么"** —— 考技术判断力。只会说优点不会说代价的，是使用者不是负责人。
3. **"这个作业/集群的数字"** —— 数据量、作业数、集群规模、SLA、优化前后的对比数字。资深候选人肚子里必须有一套自己的数字。

## 四、使用方法（三遍法 + 追问实录）

1. **第一遍（自测）**：只看问题不看答案，口头回答并录音。答不上来的标红。
2. **第二遍（实训）**：每道标红的题，去"动手印证"的实验里跑一遍——**面试官能分辨出"背的"和"跑过的"**，差别在于你能不能给出自己环境里的具体数字。
3. **第三遍（模拟）**：让朋友照着"追问链"连环发问，每题至少被追 3 层。这个档位的面试，**追问到第 3 层还没崩**才算过。
4. **深挖补充与追问实录**：各篇末尾的"深挖补充（防问倒版）"把最高频问题的机制讲到底层（shuffle 写读流程、CFS 节流、credit-based 反压、RocksDB 内存坑、G1 回收……）；05/06 两篇各附一段**追问实录**——面试官连环追问 5 层的模拟对话，先自己答再对照。

## 五、回答的黄金结构（每个答案都建议套）

> **结论先行 → 量化数字 → 取舍权衡 → 事故/案例收尾**
>
> 反例："Spark 数据倾斜有很多办法，可以加盐、可以广播……"（背诵腔，瞬间降档）
> 正例："我们大促看板作业倾斜在'下单品'上，单 partition 8GB 拖死整体 40 分钟。先用 AQE 自动 skew join 解决了 70%，剩余 30% 是 count(distinct) 类聚合，改成两阶段聚合+加盐，整体从 68 分钟降到 22 分钟。代价是代码复杂度上来了，我们只在核心链路用。"（负责人腔）

## 六、公平性说明

本手册的"参考回答"是**答题框架与要点**，不是让你逐字背——面试官对"背题感"极其敏感。所有数字示例请替换成你项目里的真实数字；没有的，就去把"动手印证"实验跑出来，它就是你的数字。
