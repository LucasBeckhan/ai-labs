## 常见发音错误纠正

### 1. TH 音（/θ/ 和 /ð/）
**错误**：把 "think" 读成 "sink"，把 "this" 读成 "dis"

**正确**：舌尖轻触上齿，气流从舌齿间通过
- think /θɪŋk/（不是 sink）
- this /ðɪs/（不是 dis）
- throughput /ˈθruːpʊt/（不是 "斯"roughput）

**练习词**：think, this, that, throughput, architecture

### 2. V 和 W 混淆
**错误**：把 "very" 读成 "wery"，把 "we" 读成 "ve"

**正确**：
- V：上齿轻触下唇，/v/
- W：嘴唇圆起，/w/

**练习词**：very, we, version, with, virtual, workflow

### 3. L 和 R 混淆
**错误**：把 "load" 读成 "road"，把 "cluster" 读成 "clustel"

**正确**：
- L：舌尖抵上齿龈，/l/
- R：舌尖卷起不接触，/r/

**练习词**：load, read, cluster, reliability, scalability

### 4. 长元音和短元音
**错误**：把 "ship" 读成 "sheep"，把 "bit" 读成 "beat"

**正确**：
- 短元音 /ɪ/：ship, bit, fit
- 长元音 /iː/：sheep, beat, feet

**练习词**：bit vs beat, ship vs sheep, fit vs feet

### 5. 词尾辅音
**错误**：省略词尾辅音，如把 "test" 读成 "tes"

**正确**：清晰发出词尾辅音
- test /test/（不是 "tes"）
- next /nekst/（不是 "nex"）
- first /fɜːrst/（不是 "firs"）

## 连读和弱读

### 1. 连读（Connected Speech）

**辅音 + 元音连读**：
- "check it out" → "check-i-tout"
- "set it up" → "set-i-tup"
- "log in" → "lo-gin"

**辅音 + 辅音合并**：
- "good day" → "goo-day"（d 和 d 合并）
- "big game" → "bi-game"（g 和 g 合并）

### 2. 弱读（Weak Forms）

**功能词弱读**：
- to: /tuː/ → /tə/
- and: /ænd/ → /ənd/ 或 /ən/
- of: /ɒv/ → /əv/ 或 /ə/
- for: /fɔːr/ → /fər/

**例句**：
- "I want to deploy" → "I wan-nə deploy"
- "Node and React" → "Node-ən React"
- "time for testing" → "time fər testing"

## 语调和节奏

### 1. 句子重音

**规则**：实词重读，虚词弱读
- **实词**：名词、动词、形容词、副词
- **虚词**：冠词、介词、连词、助动词

**例句**：
- "I **de**signed the **ar**chitecture"（designed 和 architecture 重读）
- "We **need** to **op**timize **per**formance"（need, optimize, performance 重读）

### 2. 语调（Intonation）

**陈述句**：降调 ↘
- "I implemented the feature." ↘

**疑问句**：升调 ↗
- "Did you test the code?" ↗

**列举**：升、升、降 ↗↗↘
- "I worked on **React** ↗, **Node** ↗, and **MongoDB** ↘."

**强调**：特别重读
- "I **personally** led the project."（强调 personally）

### 3. 停顿（Pausing）

**何时停顿**：
- 逗号、句号处
- 长句的意群之间
- 强调某个词之前或之后
- 思考时（用 "um", "let me think" 代替沉默）

**例句**：
- "We faced three challenges: [停顿] first, scalability; [停顿] second, performance; [停顿] and third, reliability."

## 练习方法

### 1. 影子跟读法（Shadowing）
- 找一段技术演讲视频（YouTube 上的技术会议）
- 边听边跟读，模仿发音、语调、节奏
- 每天 10-15 分钟

### 2. 录音对比法
- 朗读一段技术文本并录音
- 回听，找出问题
- 重新录音，对比改进

### 3. 最小对立对练习
- 练习容易混淆的词对：
  - ship / sheep
  - bit / beat
  - load / road
  - very / wary

### 4. 技术术语专项练习
- 每天选择 10 个技术术语
- 查词典听发音（Cambridge Dictionary, Merriam-Webster）
- 大声朗读 10 遍
- 在句子中使用

## 每日练习计划

**10 分钟日常练习**：
1. **2 分钟**：朗读技术术语表（每天 5-10 个词）
2. **3 分钟**：影子跟读一段技术视频
3. **3 分钟**：朗读一段英文技术文章
4. **2 分钟**：录音并回听一段自我介绍

**每周目标**：
- 掌握 20 个新技术术语的正确发音
- 完成 3 次影子跟读练习
- 录制 1 段完整的自我介绍或技术回答

## 面试前发音准备

面试前 1 周：
1. 复习自我介绍中的所有技术术语
2. 练习常见技术问题的回答，注意发音
3. 录音回听，纠正明显错误
4. 找朋友做模拟面试，获取发音反馈

面试当天：
1. 热身：朗读几个技术术语
2. 放慢语速，确保清晰
3. 不确定的词用简单词替代
4. 保持自信，发音错误不要停下来纠正

**记住**：面试官更关注你的技术能力和思路，发音只要清晰可懂即可，不需要完美。
