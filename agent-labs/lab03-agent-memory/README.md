## 核心问答

**Q1：Agent 记忆的两层结构与数仓分层的关系？**

> 参考答法：**完全同构**。短期记忆（上下文原文）= 明细层，超窗压缩 = 明细聚合成汇总；长期记忆（外部 KV/向量库）= 用户维表，每轮"注入" = 查询时维表关联。记忆的 TTL、去重、质量监控也全是数据工程问题——这是数据工程师做 Agent 的天然优势区。

**Q2：长期记忆全量注入 system prompt 有什么坑？（本实验实测）**

> 参考答法：**注意力抢占**——小模型会复读那条显眼的记忆而不回答当前问题（本实验 0.5B/1.5B 均实测复现）。缓解：中性"[背景资料]"消息 + "仅相关时使用"指令；**根治：按相关性选择性注入（用 RAG 检索记忆，而不是全量塞）**——又一次回到检索。

**Q3：0.5B 模型做多轮对话 Agent 的结论？**

> 参考答法：**机制可用、质量不可用**——压缩/注入/上下文拼装全部正确工作，但回复复读机化。这是"模型能力地板"的又一实证：Agent 的每个子系统要标注最低可用模型档位。
