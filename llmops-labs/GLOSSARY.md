# LLM / LLMOps 术语表（按实验出现顺序）

## 模型与推理（Lab 01）
- **参数量（0.5B/7B/70B）**：模型权重有多少个数字，规模越大能力越强、资源消耗越大
- **量化（Quantization）**：把权重从 FP16 压到 Q4 等低精度，体积显存近似线性缩小、精度损失很小
- **token**：模型处理文本的最小单位（约 0.7 个汉字或 0.75 个英文单词），计量计费的基本单位
- **上下文窗口**：模型一次能"看到"的最大 token 数，超出就要截断或检索
- **temperature / top_p**：控制输出随机性的两个旋钮；任务求稳用低温，创意求活用高温
- **max_tokens**：生成上限。**生产必设** —— 不设时小模型可能陷入无限生成（本仓库实测跑出 1.8 万 token）
- **OpenAI 兼容 API**：以 OpenAI 的 chat/completions 格式为事实标准的接口协议，换后端只改 base_url

## 网关与治理（Lab 02）
- **AI 网关**：应用与模型之间的统一入口，负责协议、路由、限流、观测
- **模型别名（alias）**：应用里写 `qwen-small`，实际指向哪个后端由网关配置决定 —— 解耦的关键
- **虚拟 key**：网关按团队/项目发放的访问凭证，可设 RPM/TPM 限流与花费预算
- **RPM / TPM**：每分钟请求数 / 每分钟 token 数 —— 两种限流口径
- **max_budget**：key 或团队的累计花费上限，超限自动拒绝或降级
- **metrics-server 无关提醒**：LLM 网关的 key 管理需要数据库（PostgreSQL），网关本身保持无状态

## RAG（Lab 03 / 04）
- **RAG（检索增强生成）**：先从知识库检索相关片段，再让模型基于片段回答 —— 治幻觉、可溯源
- **分块（Chunking）**：把长文档切成小段再入库；块大小直接影响检索质量
- **嵌入（Embedding）**：把文本变成向量，"语义相近"="向量距离近"；查询与文档必须用同一模型
- **向量库（Vector DB）**：存向量并做近似最近邻检索的数据库（chromadb/Milvus/pgvector）
- **TOP_K**：每次检索取回的片段数 —— 太小漏关键块，太大引噪声（Lab 04 用数据量化了这个权衡）
- **召回率 Recall@k**：答案依据的文档有没有被检索进 top-k —— RAG 评估的第一指标
- **忠实度（Faithfulness）**：回答是否只基于检索到的内容 —— 生成质量的代理指标
- **幻觉（Hallucination）**：模型编造知识库里没有的事实 —— 越界拒答测试专治它
- **LLM-as-judge**：用另一个模型给回答打分的评估方法，规模化评估的主流做法

## Agent 与工具（Lab 05）
- **Text2SQL**：自然语言转 SQL —— LLM 应用里最实用的场景之一
- **schema 注入**：把表结构写进 prompt，模型才知道能查什么
- **护栏（Guardrail）**：在模型输出落地前的程序化校验（SQL 白名单、强制 LIMIT）—— prompt 不是防线
- **工具调用（Function calling）**：模型在循环里调用外部工具（查库/调 API）并观察结果
- **few-shot**：在 prompt 里给几个输入输出示例 —— 实测常常比升级模型更有效

## 平台化（Lab 06 / 07 / 08）
- **hostNetwork**：Pod 共享节点网络栈 —— 本仓库用它从集群内访问宿主机的 Ollama
- **LoRA / QLoRA**：冻结基座、只训练低秩 adapter 的微调法，产物几十 MB 可插拔
- **vLLM**：高吞吐推理引擎，核心是 PagedAttention（KV Cache 分页）与连续批处理
- **KV Cache**：推理时缓存的注意力中间结果，显存占用随 token 数线性增长
- **PagedAttention**：像操作系统分页一样管理 KV Cache，消除预分配碎片、提高显存利用率
- **连续批处理（Continuous batching）**：新请求在任意解码步骤插入批次 —— GPU 利用率拉满的关键
- **TTFT / TPOT**：首 token 延迟 / 每 token 生成时间 —— 推理服务的两大体验指标
- **device plugin / time-slicing**：K8s 上声明 GPU 资源的机制 / 一张 GPU 分给多个 Pod 的共享方式
