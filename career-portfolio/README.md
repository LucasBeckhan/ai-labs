# 职业作品集 (Career Portfolio)

> 将你的学习成果转化为求职竞争力

## 模块目标

本模块帮助你：
- ✅ 构建专业的技术简历（中英文）
- ✅ 打造个人作品集展示
- ✅ 制定面试准备计划
- ✅ 优化 LinkedIn 和 GitHub 个人品牌

## 核心文件

| 文件 | 内容 | 目标 |
|------|------|------|
| [resume-templates.md](resume-templates.md) | 简历模板 + 写作指南 | 制作专业简历 |
| [project-showcase.md](project-showcase.md) | 项目展示策略 | GitHub 作品集 |
| [interview-checklist.md](interview-checklist.md) | 面试准备清单 | 系统化准备 |
| [personal-branding.md](personal-branding.md) | 个人品牌建设 | LinkedIn + 技术影响力 |

## 快速开始

### 第 1 周：简历优化
1. 阅读 [resume-templates.md](resume-templates.md)
2. 使用模板更新你的简历
3. 准备中英文双版本

### 第 2 周：作品集建设
1. 阅读 [project-showcase.md](project-showcase.md)
2. 整理 GitHub 项目（至少 3 个高质量项目）
3. 为每个项目编写清晰的 README

### 第 3 周：个人品牌
1. 阅读 [personal-branding.md](personal-branding.md)
2. 优化 LinkedIn 档案
3. 开始技术博客或开源贡献

### 第 4 周：面试冲刺
1. 阅读 [interview-checklist.md](interview-checklist.md)
2. 完成面试准备清单
3. 开始投递和面试

## 核心原则

### 1. 展示而非陈述
- ❌ "我精通 Java"
- ✅ 展示一个用 Java 实现的高性能系统项目

### 2. 量化成果
- ❌ "优化了系统性能"
- ✅ "通过 JVM 调优将响应时间从 500ms 降至 100ms"

### 3. 持续更新
- 每完成一个实验，思考如何体现在简历上
- 每个项目都记录技术决策和成果

### 4. 针对性调整
- 根据目标职位调整简历重点
- 研究公司技术栈，突出相关经验

## 成功标准

完成本模块后，你应该拥有：

- [ ] 一份专业的英文简历（1-2 页）
- [ ] 一份对应的中文简历
- [ ] GitHub 个人主页，包含 3+ 个高质量项目
- [ ] 优化的 LinkedIn 档案
- [ ] 面试准备清单（技术 + 行为）
- [ ] 至少完成 3 次模拟面试

## 时间规划

| 阶段 | 时间 | 任务 |
|------|------|------|
| 准备期 | 第 1-4 周 | 简历 + 作品集 + 品牌建设 |
| 投递期 | 第 5-8 周 | 开始投递 + 持续面试 |
| 冲刺期 | 第 9-12 周 | 密集面试 + Offer 谈判 |
