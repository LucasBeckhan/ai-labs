# 简历模板与写作指南

## 核心原则

### 1. 量化一切
用数字说话，展示具体影响：
- ❌ "优化了系统性能"
- ✅ "通过 JVM 调优将 P99 延迟从 500ms 降至 100ms"
- ✅ "领导 5 人团队，交付 3 个核心项目，节省成本 $200K"

### 2. STAR 原则
每个项目/经历用 STAR 结构：
- **S**ituation - 背景
- **T**ask - 任务
- **A**ction - 行动（你做了什么）
- **R**esult - 结果（量化成果）

### 3. 关键词优化
针对目标职位 JD，包含关键技能词：
- 技术栈：Spark, Flink, Kafka, Kubernetes
- 领域：数据仓库, 实时计算, 分布式系统
- 软技能：团队领导, 跨部门协作, 技术规划

## 简历写作要点

### 1. 动词开头，结果导向

**弱：**
```
Responsible for developing data pipelines
```

**强：**
```
Developed real-time data pipelines processing 10B events/day, enabling 
sub-second recommendation for 500M users
```

### 2. 使用强动词

**避免：**
- Worked on, Helped with, Assisted in, Responsible for

**使用：**
- Architected, Designed, Led, Implemented, Optimized, Reduced, Improved, Delivered

### 3. 量化成果

**成本相关：**
- reduced costs by 40% ($500K annually)
- saved $200K in infrastructure costs

**性能相关：**
- improved latency from 500ms to 100ms (80% reduction)
- increased throughput by 3x (from 10K to 30K requests/sec)

**规模相关：**
- processed 10TB data daily
- supported 500M users
- led team of 8 engineers

**质量相关：**
- achieved 99.99% uptime
- reduced bugs by 60%
- improved data accuracy to 99.9%

### 4. 针对性调整

**投递数据平台岗位：**
- 突出大数据框架经验（Spark, Flink, Kafka）
- 强调数据质量和可靠性
- 展示数据平台建设成果

**投递 AI 基础设施岗位：**
- 突出 ML 平台经验（模型训练、部署、监控）
- 强调 GPU 集群管理和优化
- 展示 AI Infra 项目成果

**投递管理岗位：**
- 突出团队规模和领导经验
- 强调项目交付和跨部门协作
- 展示人才培养和技术规划成果

## 常见错误

### ❌ 错误 1：过于笼统
```
Worked on big data projects using Spark and Kafka
```

### ✅ 正确：
```
Architected Spark-based ETL pipeline processing 5TB daily, reducing job 
runtime from 6 hours to 45 minutes
```

### ❌ 错误 2：职责描述而非成就描述
```
Responsible for maintaining data warehouse
```

### ✅ 正确：
```
Optimized data warehouse queries, reducing average response time from 10s 
to 500ms and supporting 1000+ daily business queries
```

### ❌ 错误 3：技术栈堆砌
```
Skills: Java, Python, Scala, C++, Go, Rust, Spark, Flink, Kafka, Hadoop, 
Hive, Presto, Druid, ClickHouse, MySQL, PostgreSQL, MongoDB, Cassandra, 
Redis, Elasticsearch, Docker, Kubernetes, Terraform, AWS, GCP, Azure...
```

### ✅ 正确：
按熟练度分类，只列出真正掌握的：
```
Languages: Java (Expert), Python (Advanced), Scala (Intermediate)
Big Data: Spark, Flink, Kafka (3+ years each)
Cloud: AWS (primary), GCP (secondary)
```

### ❌ 错误 4：忽略软技能
```
（只列技术技能）
```

### ✅ 正确：
```
Led team of 6 engineers, mentored 3 junior engineers
Collaborated with product and data science teams
Presented technical solutions to executive stakeholders
```

## 简历检查清单

- [ ] 联系方式完整（邮箱、电话、LinkedIn、GitHub）
- [ ] Summary 部分突出核心优势和关键成就
- [ ] 技术栈按类别组织，只列真正掌握的技能
- [ ] 工作经历使用 STAR 原则描述
- [ ] 每个项目都有量化成果
- [ ] 使用强动词开头
- [ ] 无语法和拼写错误
- [ ] 长度适当（应届生 1 页，资深 2 页）
- [ ] 针对目标职位调整关键词
- [ ] 有中英文双版本

## 工具推荐
